# 🐾 Kuro Fangs — كلية طب وجراحة الفم والأسنان (السنة الثالثة)

منصة الدراسة والعملي الذكية والمفتوحة بالكامل لطلاب **كلية طب وجراحة الفم والأسنان — جامعة طرابلس** (السنة الثالثة).

---

## ✨ المميزات الرئيسية

- **🔓 مفتوحة 100% بدون تسجيل دخول:** تصفح فوري لكافة الشيتات والكويزات والأدوات بدون قيود أو كلمات مرور.
- **🦷 سجل متطلبات المعمل والعملي (Pre-clinical Requirements Tracker):** متابعة إنجاز حشوات الفانتوم هيد (Class I, II, V)، تحضير التيجان والجسور (Full Cast & PFM)، وخطوات أطقم الأسنان الكاملة مع أشرطة تقدم لحظية.
- **🧮 حاسبة درجات ومعدل سنة ثالثة ومحاكي الفاينل:** تدعم نظام توزيع درجات الكلية وتحسب للطالب الدرجة المطلوبة في الفاينل للوصول لتقدير ممتاز أو جيد جداً.
- **📋 نظام الكويزات التفاعلية (Interactive MCQs Engine):** بنك أسئلة تفاعلي مع تصحيح فوري وشروحات سريرية ونقاط تفاعلية (+XP).
- **📅 بنك أسئلة السنوات السابقة:** تجميعات امتحانات النصفي والنهائي المعتمدة مع الحلول النموذجية.
- **🃏 البطاقات التعليمية التفاعلية (Flashcards):** مراجعة سريعة ومركزة للمفاهيم والمصطلحات الطبية بتقنية تقليب البطاقات ثلاثية الأبعاد.
- **💾 النسخ الاحتياطي المحلي:** إمكانية تصدير واستيراد كافة بيانات الطالب وإنجازاته كملف JSON بدون الحاجة لسيرفر خارجي.

---

## 🚀 التشغيل المحلي (Local Development)

المنظومة مصممة بدون أي حزم خارجية (Zero External Dependencies)، ويمكن تشغيلها فوراً بواسطة Node.js:

```bash
# تشغيل الخادم المحلي
node server.js
```

ثم افتح المتصفح على:
```
http://localhost:3300/
```

---

## 🛠️ التقنيات المستخدمة

- **Frontend:** Vanilla JS (ES Modules) + HTML5 + CSS3 (Design Tokens & Animations)
- **Icons:** Lucide Icons
- **Storage:** Client-side LocalStorage Engine
- **Server:** Pure Node.js HTTP Server
