# Antigravity Design & Engineering Directives

## Elite Frontend Craftsmanship & Anti-AI-Slop Rules
1. **Never generate generic "AI-template" interfaces**:
   - Avoid monotonous purple/cyan neon blobs, floating glowing spheres, and cookie-cutter 3-card grids.
   - Avoid childish 20px+ uniform rounded corners on professional controls.
   - Avoid scattered inline CSS `style="..."` attributes; use structured design tokens and semantic CSS.
2. **Elevated Visual Engineering (Linear / Raycast / Apple grade)**:
   - Use double-border elevation (`border: 1px solid ...; box-shadow: inset 0 1px 0 ...`).
   - Use rich deep slate, obsidian, and warm neutrals instead of washed-out grays.
   - Apply spring transitions (`cubic-bezier(0.16, 1, 0.3, 1)`) and tactile click states (`:active { transform: scale(0.98); }`).
3. **Arabic & English Bi-directional (RTL/LTR)**:
   - Always use CSS logical properties (`margin-inline`, `padding-inline`, `border-inline-start`).
   - Maintain typographic balance between IBM Plex Sans Arabic and Inter.
